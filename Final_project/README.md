This is the final project for Ye's EASG 690 class from Travis.

codes:
1. final_data_deal.ipynb, which contains the analysis results after the parallelization work, the notebook we analysed the results from river mask and generated figures and corresponding illustrations.
2. metrics.py, the python code which is used for parallelization work in Thinlinc. The output of such a code is folder "Analysis_Results".


Data resources:
1. xlsx sheet "data_cutoff_with_slope.xlsx", the reference data from Ye, it contains the cutoff number, cutoff type and cutoff year in sheet "infill_rate".
2. folder "angle_measuring": The folder that contains npy documents which stands for river masks.
3. folder "Analysis_Results": xlsx result generated from river masks.

Process steps:
Using matrics.py in thinlinc with the help of parallelization to generate Analysis_Result folder, and then use the "final_data_deal.ipynb" to get the figure and physical illustrations.
